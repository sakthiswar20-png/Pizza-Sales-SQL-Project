# Pizza Sales Data Analysis Using SQL

## Project Overview

This project focuses on analyzing pizza sales data using MySQL to identify business insights and understand sales performance.

The objective is to explore the dataset, analyze revenue, identify best-selling pizzas, and understand customer ordering patterns using SQL.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Database Tables

The project uses four tables:

1. **orders** – Contains order dates and times.
2. **order_details** – Contains order details and pizza quantities.
3. **pizzas** – Contains pizza sizes and prices.
4. **pizza_types** – Contains pizza names, categories, and ingredients.

## SQL Concepts Covered

- Data exploration
- Data cleaning and data type modification
- Aggregate functions (SUM, AVG, COUNT, MIN, MAX)
- Filtering using WHERE
- GROUP BY and HAVING
- INNER JOIN
- ORDER BY and LIMIT
- Subqueries
- CASE WHEN statements
- Date and time functions
- Window functions (RANK)

## Business Questions Answered

- How many orders were placed in total?
- What is the total revenue generated from pizza sales?
- Which pizza category generates the highest revenue?
- What are the top 5 best-selling pizzas?
- Which pizza size generates the highest revenue?
- Which month generated the highest revenue?
- Which day of the week has the highest number of orders?
- Which pizza types generate revenue greater than $30,000?
- How do pizzas rank based on total quantity sold?

## Key Learnings

In this project, I practiced writing SQL queries to analyze real-world business data by combining multiple tables, performing aggregations, and using advanced SQL techniques to answer business questions.
