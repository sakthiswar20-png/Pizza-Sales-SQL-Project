# Pizza Sales Data Analysis Using SQL

## Project Overview

This project focuses on analyzing pizza sales data using **MySQL** to identify sales trends, understand product performance, and generate meaningful business insights.

The main objective is to explore pizza sales data and answer real-world business questions using SQL queries, from basic data exploration to advanced analysis.

## Project Objectives

- Analyze overall pizza sales performance.
- Calculate total revenue and quantity sold.
- Identify the best-selling and highest-revenue-generating pizzas.
- Analyze sales performance by pizza category and size.
- Identify monthly and daily sales trends.
- Rank pizzas based on quantity sold.
- Practice SQL concepts using real-world business questions.

## Tools & Technologies

- **Database:** MySQL
- **SQL Editor:** MySQL Workbench
- **Dataset Source:** Maven Analytics – Pizza Sales Dataset

## Dataset Description

The dataset consists of four tables:

| Table Name | Description |
|---|---|
| `orders` | Contains order dates and times. |
| `order_details` | Contains order details and pizza quantities. |
| `pizzas` | Contains pizza IDs, sizes, and prices. |
| `pizza_types` | Contains pizza names, categories, and ingredients. |

## Data Preparation

The following data preparation steps were performed:

- Created the `pizza_sales` database.
- Imported the four dataset tables into MySQL.
- Renamed the `date` column to `order_date`.
- Renamed the `time` column to `order_time`.
- Changed the data types of `order_date` and `order_time` to DATE and TIME respectively.
- Explored the imported tables.

## SQL Concepts Used

This project covers the following SQL concepts:

- SELECT and DISTINCT
- WHERE and ORDER BY
- Aggregate Functions (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY and HAVING
- INNER JOIN
- LIMIT and OFFSET
- Subqueries
- CASE WHEN Statements
- Date and Time Functions
- Window Functions (RANK)

## Business Questions Answered

The project answers 23 business questions, including:

1. How many orders were placed in total?
2. How many individual pizza records are present in order details?
3. How many unique pizza types are available on the menu?
4. What are the different pizza categories available?
5. What is the total quantity of pizzas sold?
6. What is the total revenue generated from pizza sales?
7. What is the average price of pizzas?
8. What are the highest-priced and lowest-priced pizzas?
9. Which pizzas are priced above $15?
10. Which pizzas belong to the Chicken category?
11. Which pizza types generated revenue greater than $30,000?
12. How many pizzas were sold in each category?
13. What is the total revenue generated by each pizza category?
14. What are the top 5 best-selling pizzas?
15. What are the next 5 best-selling pizzas?
16. Which pizza size generates the highest revenue?
17. Which month generated the highest revenue?
18. Which day of the week has the highest number of orders?
19. How can pizzas be categorized based on their prices?
20. How many pizzas belong to each price category?
21. Which pizzas are priced above the average pizza price?
22. Which categories have revenue greater than the average category revenue?
23. How can pizzas be ranked based on total quantity sold?
